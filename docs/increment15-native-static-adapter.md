## Implemented boundary

`framewright/native_handoff.py` reads actual embedded GLB bytes, validates binary accessor bounds/indices and finite attributes, preserves node/parent/pivot identities, and derives triangle counts and bounds from exported geometry. It rechecks source/project/handoff receipts, requires absolute local paths without traversal/reparse/UNC indirection, and produces a strict versioned proposal. Changed plan fields cannot select executable code: verification recompiles the proposal from pinned inputs.

The compiler admits static opaque core glTF geometry and embedded PNG/JPEG PBR maps. Skin, animation, morph, extensions, sparse accessors, external URIs, mirrored/sheared transforms and conflicting transfer/normal roles on one texture still refuse. The GLB allowance defaults to 64 MiB; a caller can explicitly select up to 512 MiB. Independent fixed limits remain 8 MiB JSON, 512 nodes/meshes, 256 materials/images/textures/samplers, 4096 accessors/views, 16 million scalar decodes including repeated primitive references, and local vertex coordinates within one million metres per axis.

PBR records retain exact embedded payload hashes, MIME types, dimensions, image/texture/sampler references, source filters, UV sets, factors and channel conventions. PNG admission verifies CRCs, bounded compressed rows/filter bytes and palette/sRGB/transparency structure for noninterlaced 8/16-bit grayscale/RGB with optional alpha. Metadata constraints follow the [W3C PNG specification](https://www.w3.org/TR/png-3/). JPEG admission verifies bounded baseline/progressive container structure and complete scan/end markers; it does **not** decode entropy or verify pixels. Per-image dimensions stop at 8192×8192. The aggregate allowance defaults to 134,217,728 pixels (two 8K maps); callers may explicitly choose up to 536,870,912 pixels (eight 8K maps). Zero permits geometry without images. Image bytes and a structurally valid container do not establish native appearance.

Native plan schema **1.1** records both exact integer allowances in `admission_budgets`. Verification validates that strict object and recompiles with the same limits; old proposals require recompilation. Larger allowances do not change geometry, per-image, JSON or native authorization limits. Hashing and parsing are bounded during reads, including every source rehash, so file growth after stat preflight cannot bypass the selected allowance. Exact parsed bytes also match their initial receipt, rejecting a transient same-size replacement even if the original file returns before final hashing. GLB headers/JSON limits reject invalid chunks before copying payloads. Exhausted PNG pixel budgets refuse at IHDR before decompression. PNG input and output feeds both stop at 64 KiB, and validated chunk headers are re-walked without retaining a per-chunk list. This prevents large IDAT tail copying and tiny-chunk memory amplification.

`framewright/unreal_static.py` is inert on import; only explicit backend construction inside Unreal loads `unreal`. It uses `InterchangeManager.import_scene` with replacement/redirectors disabled, an explicit new level, and the three installed GLB scene pipelines. It imports a hierarchy rather than merging the cabinet's door pivot into one static mesh. Exact labels/parent identities, transformed bounds, triangle counts and material slot names must match observations; missing, renamed, extra or flattened nodes fail before final saves. Mesh slot material objects and each component's effective material must also resolve to the expected owned material; matching labels cannot conceal swapped or foreign assignments.

Before saves, the backend reads actual material-instance factors, texture switches/references, UV sets, tiling, offset/scale/rotation, normal scale, occlusion strength, blend mode and inherited sidedness. Texture observations include dimensions, sRGB, normal green-channel flip, compression, wrap and filter settings. Missing parameter names refuse instead of accepting a getter's default zero. Parent assets are restricted to the installed opaque default/Substrate GLTF parents. Observations are compared with a separate `1e-5` parameter tolerance; raw GLB PBR metadata is never copied into the observed result as proof. The actual mesh component must be the verified actor root, so an offset child mesh cannot hide behind correct actor transforms. Unexpected native behavior is not silently normalized into a pass.

This is a **settings contract**, not shader/pixel/render parity. Installed Interchange collapses several glTF minification filters to its default and does not map `magFilter`; the source settings remain recorded without claiming equivalence. Native apply currently requires every texture to be bound and distinct native texture labels. Reused image bytes through separately named textures can retain distinct settings. Native API compatibility, decoded texture contents, exact surface/UV data, cold reload and rendered appearance still require the actual engine fixture.

The entrypoint requires the exact saved project, engine 5.8.3, no PIE, no dirty packages, an absent owned namespace, explicit owner/authorization arguments and the existing exclusive Windows `Saved/NarrativeArt.lock` protocol. The lock is coordination evidence, not authentication or permission. The JSON plan does not grant native authorization. No executable path, Python source, shell command or remote-execute request is accepted by the plan.

Only the returned owned package list and new owned staging level can be saved; the list cannot be empty. No existing asset is replaced, no level is cleared/renamed, and no global save is used. Source hashes are rechecked before mutation and before/after final saves. Failures retain an explicit partial-state receipt; already-created/saved owned assets are not broadly deleted. Unreal's `new_level` saves the new empty `.umap` before import, so a failed import can leave an empty owned map. This is not an atomic transaction.

The adapter restores the original **clean saved level** after success/failure when safe. If foreign packages become dirty or the active world changes unexpectedly, it refuses automatic restoration and reports that failure. This is not preservation of arbitrary editor UI/selection/viewport or third-party plugin state. A native owner must arrange the authorized window; the helper never launches/restarts an editor or modifies plugin/network configuration.

## Primary source for units and pipeline selection

The installed Unreal 5.8.3 source, not the historical Unity migration permutation, defines the expectation:

- `Engine/Plugins/Interchange/Runtime/Source/Parsers/GLTFCore/Private/GLTF/ConversionUtilities.h:16–42`: glTF `(x,y,z)` maps to Unreal `(x,z,y)`; quaternion vector components become `(-x,-z,-y)` with `w` retained.
- `Import/Private/Gltf/InterchangeGltfPrivate.h:24` defines `GltfUnitConversionMultiplier = 100.f`; `InterchangeGltfTranslator.cpp:617` scales node translations. Mesh bounds are compared in centimetres, using the same axis swap.
- `Engine/Config/BaseEngine.ini:3786` names the scene stack: `DefaultGLTFSceneAssetsPipeline`, `DefaultGLTFPipeline`, `DefaultSceneLevelPipeline`. The backend pins those engine assets instead of accepting a caller-selected/project pipeline.

## Reproduce without native execution

Run `scripts/prepare_native_import.py` using explicit absolute `--handoff`, `--project-root`, `--source-root` and new `--output` JSON paths. Output must be outside the game and source roots. The CLI never imports Unreal or contacts an endpoint and refuses output replacement.

For the retained three-map 8K cabinet, explicitly add `--max-glb-bytes 536870912 --max-total-image-pixels 201326592`. The Python `inspect_glb` and `compile_plan` functions expose matching keyword-only arguments. Omitting either option retains its conservative default; no texture-resolution heuristic silently raises limits. These resource allowances establish offline admission, not Unreal compatibility or runtime texture residency.

The separate `scripts/unreal_import_static.py` is a fixed entrypoint for a **later authorized Unreal window**. It defaults to preview and reserves a new report before native operations. Apply additionally requires `--apply`, `--authorize-native` and `--owner`; these flags are not an invitation to bypass the shared native owner. Do not expose this entrypoint through arbitrary-code MCP execution or invoke it from Blender background jobs. No native invocation is included in the offline pilot.
